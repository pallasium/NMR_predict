# NMR予測(xtb + ORCA): 1H / 13C / 31P / 19F / 11Bと2次元(COSY / HSQC / HMQC / HMBC / TOCSY / NOESY / ROESY)

SMILESからNMRスペクトル(1Dと2D)を予測してPNGに出す。1HはJ結合による分裂も含めて表示する。

- 構造最適化: [xtb](https://github.com/grimme-lab/xtb) (GFN2-xTB)
- 化学シフト: [ORCA](https://orcaforum.kofo.mpg.de)のDFT (GIAO)で遮蔽定数を計算し、TMSを引く。汎関数は自動で選ぶ: **13Cを含む計算(13C, HSQC, HMQC, HMBC)はPBE0/def2-SVP、それ以外(1Hなど)はPBE/def2-SVP** (理由は「精度の検証」)
- J結合: xtbの構造から経験式(Karplus型など)で見積もる
- スペクトル: 核スピンの厳密なシミュレーション(2次の効果・屋根効果を含む)

12スレッドのPCで、エタノールやイブプロフェンは約1分、分子量の大きい分子(約900基底関数)でも4分程度。

## 対応する核種
`--nuc`で指定する(既定は1H)。ORCAは1回の計算で全原子の遮蔽定数を出すので、核種を増やしても、基準物質の計算(初回のみ)以外に時間はほとんど増えない。

| 核種 | 基準物質 | 表示 |
|---|---|---|
| 1H | TMS | J結合による分裂つき(経験式) |
| 13C | TMS | 1H脱カップリングの1本線 |
| 31P | H3PO4 | 1本線 |
| 19F | CFCl3 | 1本線 |
| 11B | BF3-OEt2 | 1本線(四極子核なので、線幅100 Hzで描く) |

```
python nmr.py "Fc1ccccc1" --nuc 19F,13C       # 複数の核種 (カンマ区切り)
python nmr.py "CP(C)(C)=O" --nuc 1D          # 全部 (分子にない元素は自動でスキップ)
```
引数なしで起動すると、先に「何を計算するか」を聞かれる(空Enterで1H)。

### 精度の検証: PBE / PBE0 / r2SCAN0の比較(CDCl3のCPCM, 補正なし)
同じxtbの構造に対して、3つの汎関数(すべてdef2-SVP, GIAO)で計算し、文献値と比べた。コードとデータは`benchmark/` (`python benchmark/run_benchmark.py <PBE|PBE0|r2SCAN0>`で再現、`python benchmark/analyze.py`で集計)。生の計算結果(CSV)は、ORCAのEULAの条件により、公開していない(`.gitignore`で除外。再生成できる)。

- **対象**: 有機小分子8つ(エタノール, 酢酸エチル, THF, DMF, トルエン, アニソール, ベンズアルデヒド, ピリジン)。1Hは55個、13Cは39個の原子。
- **正解**: 実測ではなく**文献値** (CDCl3, TMS基準)。うち5分子(エタノール, 酢酸エチル, THF, DMF, トルエン)は、Fulmerら(Organometallics 2010, 29, 2176)の表と照合した。残りの3分子(アニソール, ベンズアルデヒド, ピリジン)は、SDBS(産総研)の1H / 13C(CDCl3)と照合した。差は1Hで最大0.06 ppm、13Cで最大0.24 ppmで、SDBSの値に置き換えても、MAEの変化は0.02 ppm以下だった(値は、SDBSの値を丸めても一致しない箇所が多く、SDBSからの転記ではない。SDBSの条件は「参考文献」の注記を参照)。
- **比較の方法**: 予測と文献の信号を原子ごとに展開してppmの順に並べ、1対1で対応づけた(帰属なし。実際の誤差より小さく出うる)。交換性H (OH, NH, COOH)は除いた。誤差 = 予測 − 文献。

| 核種 | 手法 | MAE (ppm) | RMSE | 平均の偏り | 最大誤差 |
|---|---|---|---|---|---|
| 1H | PBE | **0.14** | 0.16 | +0.01 | 0.26 |
| 1H | PBE0 | 0.16 | 0.18 | +0.05 | 0.35 |
| 1H | r2SCAN0 | 0.18 | 0.22 | +0.10 | 0.47 |
| 13C | PBE | 3.82 | 4.39 | −2.62 | 13.5 |
| 13C | PBE0 | **1.39** | 1.73 | −0.38 | 5.9 |
| 13C | r2SCAN0 | 1.62 | 1.87 | −0.16 | 5.0 |

- **13Cは、PBEよりPBE0 / r2SCAN0の方が大幅によい** (MAE 3.8 → 1.4〜1.6 ppm)。PBEは、全体に約2.6 ppm低く出て、特にsp2炭素(芳香環)の誤差が大きい(MAE 4.7 ppm、PBE0は1.4 ppm)。
- **1Hは、3手法とも0.14〜0.18 ppmで、差は小さい。** PBEがわずかによいが、分子が8つなので、この差が一般的に成り立つとは言えない(分子ごとには、PBEがよいもの[トルエン, ピリジンなど]と、PBE0 / r2SCAN0がよいもの[エタノール, 酢酸エチル, THF]に分かれた)。
- Fulmerらの表で照合した5分子だけで集計しても、同じ傾向だった(13C: PBE 3.66 / PBE0 1.47 / r2SCAN0 1.87 ppm、1H: 0.158 / 0.141 / 0.137 ppm)。
- 分子を単位にしたブートストラップ(10000回、`benchmark/stats.py`、結果は`benchmark/results/stats.md`)では、**13CのPBE0 − PBEの差(−2.4 ppm、95%区間 −2.9〜−1.9)は偶然ではない**。1Hの3手法の差は、区間が0をまたぎ、偶然の範囲。13CのPBE0とr2SCAN0の差(−0.2〜−0.4 ppm)は、区間が0を外れるが、分子が5〜8個なので、楽観的な見積もりである。
- **このため、既定(`method`が`auto`)では、13Cを含む計算はPBE0、それ以外はPBEを使う。** 1HだけならPBE0にしても精度は変わらず、PBEの方が1.6〜1.9倍速いため。r2SCAN0は、今回の検証ではPBE0より遅く、精度の利点もなかったので、自動では選ばない。設定ファイルで`method`を指定すると、それが優先される(下の「設定」)。

### 他の核種(19F / 31P / 11B): 精度は低く、PBE0でも改善しない
標準物質の表の値(19F: 19F NMR Reference Standards, vs CFCl3 / 31P: 代表的な31P化学シフトの表, vs 85% H3PO4)と比べた。**表に溶媒の記載がなく、CDCl3の計算との比較には、数ppmの溶媒の差が含まれうる。** 括弧内は予測 − 文献。

| 核種 | 分子 | 文献(ppm) | PBE | PBE0 | r2SCAN0 |
|---|---|---|---|---|---|
| 19F | フルオロベンゼン | −113.15 | −100.2 (+13.0) | −95.7 (+17.4) | −95.4 (+17.7) |
| 19F | ベンゾトリフルオリド | −63.72 | −74.3 (−10.5) | −59.8 (+3.9) | |
| 19F | ヘキサフルオロベンゼン | −164.9 | −166.3 (−1.4) | −152.2 (+12.7) | |
| 19F | トリフルオロ酢酸 | −76.55 | −86.0 (−9.4) | −72.1 (+4.5) | |
| 31P | トリメチルホスフィンオキシド | 36.2 | 26.1 (−10.1) | 26.4 (−9.8) | 30.8 (−5.4) |
| 31P | トリエチルホスフィンオキシド | 48.3 | 44.8 (−3.5) | 42.4 (−5.9) | |
| 31P | トリメチルホスフィン | −62 | −65.6 (−3.6) | −75.8 (−13.8) | |
| 11B (未照合) | ホウ酸トリメチル | 約18 | 14.2 (−3.9) | 15.8 (−2.3) | 15.5 (−2.6) |

- 19FのMAEはPBE 8.6 / PBE0 9.6 ppm (4分子)、31PはPBE 5.7 / PBE0 9.8 ppm (3分子)。**差の符号が分子ごとに揃わず、汎関数を変えても改善しない** (PBEは19Fが低く偏り、PBE0は高く偏る)。
- 基底関数(def2-SVP)が小さいことが原因の候補。NMR用の基底関数pcSseg-1 (def2-SVPと同程度の大きさ)をPBE0で試したが、**改善しなかった**: 19Fはフルオロベンゼンが+17.4 → −2.8 ppmと改善したが、ベンゾトリフルオリドは+3.9 → −10.6 ppmと悪化(4分子のMAEは11.2 → 12.8 ppm)、31Pも悪化(Me3PO −9.8 → −15.2 ppm)。有機8分子の13Cは、MAE 1.39 → 6.04 ppmと悪化した(+6 ppmの一定のずれがあり、それを除いても、ばらつきはdef2-SVPより大きい)。1Hも0.156 → 0.261 ppm。結果は`benchmark/results/basis.md`。def2-TZVPなどの大きな基底関数は、時間の都合で試していない。
- **定量的な19F / 31P / 11Bは、期待しないこと。** 同じ系統の化合物の実測値で、補正(下)するのが現実的。
- 11Bの値(約18 ppm)は、出典で確認できていない。トリフェニルボラン、p-ジフルオロベンゼン、トリエチルホスフィン、Me3P=Sは、時間の都合で追加の計算をしていない。

### 溶媒(DMSO-d6)
DMSO-d6 (CPCM(DMSO))でも、Fulmerら(2010)の値と、酢酸エチル・DMF・トルエンの3分子で比べた。1HのMAEはPBE 0.125 / PBE0 0.146 ppm (CDCl3では0.143 / 0.151)、13CはPBE 3.62 / PBE0 1.52 ppm (CDCl3では3.95 / 1.43)。**3分子だけだが、CDCl3と同じ精度で、PBE0が13Cでよい傾向も同じ。** 他の溶媒(D2O, CD3ODなど、水素結合の強いもの)は、検証していない。

### 補正(スケーリング)
`nmr_config.json`に、核種ごとに`[傾き, 切片]`を書くと、`δ = 傾き × (σ基準 − σ) + 切片`で補正される。例:
```
{
  "xtb": "...", "orca": "...",
  "scale": { "13C": [1.0, -2.5], "19F": [1.0, -13.0] }
}
```
補正の値は、自身で測定した(または文献にある)同系統の化合物で、予測と実測の差を見て決める。このリポジトリには、補正値は入っていない。

## 2次元NMR (COSY / HSQC / HMQC / HMBC / TOCSY / NOESY / ROESY)
予測したシフトとJ結合、構造から、2Dスペクトルを描く。**位置の予測が中心で、強度は定性的** (パルス系列・位相・緩和は考えない)。上と左に1Dのトレースを付ける。

| 2D | 横軸 / 縦軸 | 相関ピークの作り方 |
|---|---|---|
| COSY | 1H / 1H | Jが`--cosy-jmin` (既定2 Hz)以上のHグループの組。強度はJに比例 |
| HSQC | 1H / 13C | C-Hの直結。CH, CH3は赤(+)、CH2は青(−)の編集型 |
| HMQC | 1H / 13C | HSQCと同じC-Hの直結。多重度の編集はなく、すべて紫(同じ位相)。1H-1HのJによる縦方向の広がりは描かない |
| HMBC | 1H / 13C | 2結合(弱)と3結合(強)離れたC-Hの組 |
| TOCSY | 1H / 1H | 結合でつながったHグループ(スピン系)の全部の組。つながりが遠いほど弱い |
| NOESY | 1H / 1H | 空間的に近いHグループの組(実効距離 約5 Å 以内)。xtbの全配座の<r⁻⁶>のボルツマン平均 |
| ROESY | 1H / 1H | NOESYと同じ距離の見積もり。交差ピークは青で、分子量によらず対角(灰)と逆の位相 |

```
python nmr.py "CC(C)Cc1ccc(cc1)C(C)C(=O)O" --calc COSY,HSQC       # 選んだ 2D だけ
python nmr.py "CC(C)Cc1ccc(cc1)C(C)C(=O)O" --calc 1H,13C,2D       # 1D と全部の 2D
```
`--calc`は、核種(1H, 13C, 31P, 19F, 11B)と2Dの名前をカンマ区切りで並べる。`1D`は全核種、`2D`は全部の2次元。`--nuc`は同じ意味の別名。

### 必要な計算だけを実行する
選んだものに必要な計算だけが走る。

| 選んだもの | 計算する基準物質 | 経験式のJ結合 | 配座の座標 |
|---|---|---|---|
| 1H | TMS (H) | ○ (`--no-j`で省略) | |
| 13C | TMS (C) | | |
| 31P / 19F / 11B | H3PO4 / CFCl3 / BF3-OEt2 | | |
| COSY, TOCSY | TMS (H) | ○ | |
| HSQC, HMQC, HMBC | TMS (H, C) | | |
| NOESY, ROESY | TMS (H) | | ○ (全配座を使う) |

ORCAの遮蔽定数の計算は、何を選んでも1回(全原子まとめて)。基準物質の計算は初回のみで、保存される。

### 2Dの限界
- 13Cのシフトの誤差(数ppm)が、そのままHSQC / HMQC / HMBCの縦軸のずれになる。
- HMBCは、実際には2J / 3Jの大きさで強度が変わる。ここでは3結合を1.0、2結合を0.5とした固定の重み。4結合以上(W型など)は出さない。
- COSYはJが小さい(約2 Hz未満)と出ない。経験式のJは ±1〜2 Hzの目安。
- NOESYは、xtbの配座(既定5個)の範囲の平均。配座の探索は不十分なことがある。分子量によるNOEの符号の変化(ゼロ交差)は考えない。ROESYはNOESYと同じ距離から作るので、強度の違いは出ない(符号と色だけが違う)。TOCSY由来のアーティファクトや化学交換のピークは描かない。
- ジアステレオトピックなH (CH2の2つのH)は区別せず、同じ位置に出る。交換性H (OH, NH)は2Dに含めない。

ORCAとxtbは、このリポジトリに含まれていない。それぞれのライセンスに従って、自分で入手・インストールする。

### 1. Pythonの環境
```
python -m venv venv
venv\Scripts\activate
pip install rdkit numpy matplotlib
```

### 2. xtb
1. <https://github.com/grimme-lab/xtb/releases>から、Windows版のビルド(zip)をダウンロードする。
2. 好きなフォルダに展開する。`xtb.exe`の場所を控える。
3. 確認: `xtb.exe --version`を実行して、バージョンが表示されること。

### 3. ORCA
1. <https://orcaforum.kofo.mpg.de>でアカウントを作り(無料)、ORCA 6のWindows版をダウンロードする。
   - 学術利用は無料。商用利用は別途ライセンスが必要。利用条件はORCAのEULAを各自で確認すること。
2. 展開して、`orca.exe`の場所を控える。
3. **Microsoft MPI** をインストールする(並列計算に必要)。
   - MicrosoftのMS-MPIのページから、`msmpisetup.exe`をダウンロードして実行する。
   - 確認: `mpiexec`コマンドが使えること(`C:\Program Files\Microsoft MPI\Bin\mpiexec.exe`)。
4. 確認: 小さな入力ファイルでORCAが走ること。このツールは、`orca.exe`を**フルパス**で呼び出す。ORCAの並列計算は、フルパスでの呼び出しが必須。

### 4. 設定ファイル
`nmr_config.example.json`を`nmr_config.json`にコピーして、xtbとORCAの場所を書き換える。
```

  "xtb": "C:\\path\\to\\xtb.exe",
  "orca": "C:\\path\\to\\orca.exe"
}
```
`nmr_config.json`は`.gitignore`で除外されている。環境変数`XTB_PATH`, `ORCA_PATH`でも指定できる。

### 5. 動作確認
```
python nmr.py CCO
```
エタノールのCH2 (約3.8 ppm)、CH3 (約1.0 ppm)のスペクトルが開き、`out\`に画像が保存されれば成功。

### トラブルシューティング
| 症状 | 原因と対処 |
|---|---|
| `xtb の場所が分かりません` | `nmr_config.json`のパスを確認する(バックスラッシュは`\\`と2つ書く) |
| ORCAが`For parallel runs ... full path`で止まる | `orca.exe`をフルパスで指定する(設定ファイルの`orca`) |
| ORCAがすぐ終了する / MPIのエラー | MS-MPIをインストールする。再起動が必要な場合がある |
| メモリ不足でORCAが落ちる | `--nprocs 4`などでコア数を減らす。他のアプリを閉じる |
| 画像の日本語が文字化けする | Windows標準のフォント(Yu Gothic, Meiryo)を使う。入っていない環境では英語のみ表示される |

## 使い方
### 対話モード(引数なし)
```
python nmr.py
```
最初に「計算するもの」(1H, 13C, 31P, 19F, 11B, COSY, HSQC, HMQC, HMBC, TOCSY, NOESY, ROESY。カンマ区切り、`1D` = 全核種、`2D` = 全2次元。空Enterで1H)を聞かれ、続いて`SMILES または Compound_ID:`を聞かれる。SMILESが空なら終了。完成した画像は自動で開く。

### コマンドで指定
```
python nmr.py "COc1ccccc1"                    # SMILES を直接指定
python nmr.py Anisole                         # nmr.csv の Compound_ID
python nmr.py "CCO" --name ethanol --solvent DMSO-d6 --mhz 600
python nmr.py "CCO" --no-j                    # J 結合なし
```
| オプション | 内容 |
|---|---|
| `--solvent` | CDCl3 (既定), DMSO-d6, CD3OD, D2O, acetone-d6, C6D6 |
| `--nconf` | xtbで最適化する配座数(既定5)。Jの平均に使う |
| `--orca-conf` | ORCA (DFT)で計算する配座数(既定1)。増やすと遅いが、柔軟な分子で精度が上がる |
| `--nprocs` | 使うコア数。省略すると論理コア数を自動検出して全部使う |
| `--mhz` | 表示する装置周波数(既定400) |
| `--calc` (`--nuc`) | 計算するもの。核種(1H, 13C, 31P, 19F, 11B)と2D (COSY, HSQC, HMQC, HMBC, TOCSY, NOESY, ROESY)をカンマ区切りで。`1D` = 全核種、`2D` = 全2次元。既定1H |
| `--cosy-jmin` | COSY / TOCSYで相関を出すJの下限(Hz)。既定2.0 |
| `--no-j` | J結合を計算しない(1Hのスペクトルのみに関係) |
| `--no-assign` | 原子とピークの対応図(`_assign.png` / `_assign.html`)を出力しない |
| `--no-open` | 完成した画像を自動で開かない |
| `--name` | 出力ファイル名 |

### 化合物の一覧
- `nmr.csv`: サンプル。`Compound_ID,SMILES,Solvent`の列を持つ。ここにあるIDは、名前だけで呼び出せる。

### 出力
- `out/<name>_<COSY|HSQC|HMQC|HMBC|TOCSY|NOESY|ROESY>.png`と`.csv`: 2Dスペクトルと、相関ピークの一覧
- `out/<name>_<核種>.png`と`.csv`: 1Dスペクトル(1Hは`_1H`)
- `out/<name>_1H.png`: スペクトル(全体図+ ピークごとの拡大図)
- `out/<name>_1H.csv`: シフト(ppm)、Hの数、原子番号
- `out/<name>_J.csv`: J結合(Hz)
- `out/<name>_<核種>_assign.png`と`_assign.html`: **どの原子がどのピークか**を示す図(下記)

1Hの表には、各ピークの**多重度とJ (Hz)** も付く(`multiplicity`, `J_Hz`列。画面には`δ 7.45 (d, J = 8.1 Hz, 2H)`の形式の1行も出る)。経験式のJを使った一次の分裂則(n+1則)で決める。2次の効果が強い場合(シフト差がJの4倍未満)・分裂の組が4つ以上・線が16本超・隣のピークと重なる場合は`m`、交換性Hは`br s`。`--no-j`では付かない。

#### 原子とピークの対応図
- `_assign.png`: 構造式の原子に番号と色を付け、スペクトルのピークに同じ番号と色、δを併記する。等価な原子は`5,9`のようにまとめる。ピークのない原子(C=OのCやOなど)は灰色。
- `_assign.html`: ブラウザで開く。原子をクリックするとピークが光り、ピークの棒や表の行をクリックすると原子が光る。もう一度クリックで解除。表示用に線幅を太くしてあり、多重度は表示しない。
- 番号はRDKitの原子index(0始まり)で、`out/*.csv`の`atom_indices`列と同じ。1Hは、Hが結合している原子の番号(CH3の3つのHは、そのCの番号1つ)。O-H / N-Hは参考値。

途中の計算は`work/`に残り、同じ条件で再実行すると再利用される。基準のTMSは`cache/`に保存される(設定を変えた後の初回だけ計算する)。

### 設定(nmr_config.jsonの他の項目)
`method` (既定`auto`: 13Cを含む計算はPBE0、それ以外はPBE。`PBE`や`PBE0`などを書くと、全部の核種にそれを使う), `basis` (既定def2-SVP), `orca_extra` (ORCAの追加キーワード。既定`auto`: PBEのときは`def2/J`、それ以外は空), `orca_conf` (既定1), `nprocs`, `maxcore_mb` (どちらも既定`auto`)

13Cを含むときにPBE0を使うのは、上の検証のとおり、13CのMAEが約3.8 → 1.4 ppmに下がるため。速さを優先して、13CもPBEで計算したいとき、またはr2SCAN0を試したいときは、`nmr_config.json`で指定する:
```
{ "method": "PBE",     "basis": "def2-SVP", "orca_extra": "def2/J" }
{ "method": "PBE0",    "basis": "def2-SVP", "orca_extra": "" }
{ "method": "r2SCAN0", "basis": "def2-SVP", "orca_extra": "RIJCOSX def2/J" }
```
計算時間(ORCAのGIAOのみ。xtbと、初回だけのTMSの基準計算は含まない。12スレッド、各1回の計測):

| 基底関数の数 | PBE | PBE0 | r2SCAN0 |
|---|---|---|---|
| 約400 | 48秒 | 79秒(1.6倍) | 102秒(2.1倍) |
| 約540 | 69秒 | 122秒(1.8倍) | 148秒(2.1倍) |
| 約1050 | 3分54秒 | 7分13秒(1.9倍) | 8分9秒(2.1倍) |

PBE0はPBEの約1.6〜1.9倍、r2SCAN0は約2.1倍で、**分子が大きいほど差が開く** (PBEはRI近似でクーロン項を速く計算するため)。基底関数が200程度の小さな系では、差はほとんどなかった。13Cが目的なら、PBE0が精度と時間のバランスがよい(r2SCAN0は、今回の検証ではPBE0より遅く、精度の利点もなかった)。

## 計算の流れ
1. RDKitで配座を生成(ETKDG + MMFF)
2. xtb (GFN2, ALPB溶媒)で構造最適化。エネルギーでボルツマン重みを計算(298 K)
3. 最も安定な配座(既定1個)について、ORCAでGIAO遮蔽定数を計算(13Cを含むならPBE0/def2-SVP、そうでなければPBE/def2-SVP + RI、CPCM)。TMSを同じ条件で計算して引き、化学シフトにする。画面の1行目に、選ばれた汎関数が出る
4. J結合は、xtbの**全配座**の構造から経験式で見積もり、ボルツマン重みで平均する(CH3 / CH2の等価なHは回転で平均)
5. 核スピンの厳密なシミュレーションでスペクトルを作る
6. PNGとCSVを出力

### J結合の経験式
| 種類 | 値 |
|---|---|
| 3J (sp3-sp3, H-C-C-H) | Haasnoot-Altona型`13.7 cos²φ − 0.73 cosφ` (φ = 二面角、置換基の補正なし) |
| 3J (アルケン) | cis 10.5 Hz / trans 16.5 Hz (二面角で判定) |
| ベンゼン環 | オルト7.6 / メタ1.5 / パラ0.6 Hz |
| 5員環の芳香環3J | 3.5 Hz |
| アルデヒドH-C-C(=O)H | 2.5 Hz |
| アリル型4J | 1.5 Hz |
| 上記以外 | 0 (結合なし扱い) |

## 実測データとの比較(検証)
著者が測定した実測ピークと比べた。化合物の種類が限られた小規模な確認で、他の化合物系でも同じ精度になる保証はない。

| 核種 | 対象 | MAE | 誤差0.2 ppm以内 | 0.5 ppm以内 |
|---|---|---|---|---|
| 1H (C-H) | 8化合物(779 H) | **0.36 ppm** | 61% | 88% |
| 1H (O-H / N-H) | 同上(49 H) | 0.71 ppm | 25% | 62% |
| 13C | 7スペクトル(154 C) | **3.9 ppm** | | |

- 13Cは、7スペクトルのうち6つがMAE 1.5〜3.5 ppm。残りの1つ(塩)は、実測に不純物とみられるピークが多く、対応づけが崩れて9.8 ppmになった。
- 比較は、**帰属を使わない**方法(1H: 順序対応(最適輸送)、13C: 実測の各ピークを予測の炭素に1対1で割り当て)なので、実際の誤差より小さめに出ることがある。
- 実測と化合物の対応は、ファイル名から推定したもので、確認していない。濃度・会合の影響も含む。
- **塩を、イオン対のままDFT (PBE)で計算すると、13Cが約50 ppmずれた** (アニオンからカチオンへの人工的な電荷移動)。そのため、塩は、イオンごとに別々に計算するようにした。

## 限界
- 塩(SMILESが複数の断片に分かれる)は、イオンごとに別々に計算する。イオン対の相互作用(NH3+ とアニオンの水素結合など)は考えない。
- 異核種(13C, 31P, 19F, 11B)は、1H脱カップリングの1本線で表示する。**異核種間のJ結合(C-F, C-P, P-F, F-Fなど)は計算していない。** 13C-19Fの1J (約250 Hz)や、13C-31Pの1Jのような大きな分裂は出ない。
- 異核種のシフトは、1Hより誤差が大きい(上の表のとおり)。定量的に使うには、補正が必要。
- 11Bのような四極子核の線幅は、固定値(100 Hz)で描いている。実際の線幅は環境によって大きく変わる。
- 基準物質(H3PO4, BF3-OEt2)は、単分子を連続誘電体で計算している。実際は、水素結合や会合した状態で測定するので、基準の値に誤差が入る。
- 13Cを含む計算はPBE0 (自動選択)のため、PBEより約1.6〜1.9倍遅い(大きい分子ほど差が開く)。PBEにすると13Cは約2.6 ppm低く偏る(MAE 3.8 ppm)。検証は有機小分子8つと文献値だけなので、大きな分子や、ヘテロ原子の多い分子で同じとは限らない。
- O-H / N-Hなどの交換性Hは溶媒・濃度で大きく動くので、`*`を付けた参考値の1本線で表示する(COOHなども実測より大きくずれる)。
- J結合は経験式のため、電気陰性な置換基による変化、環の構造、長距離結合(W型など)は入らない。±1〜2 Hz程度の目安。
- 配座を1個しかDFTで計算しないので、柔軟な分子ではシフトが配座平均からずれることがある。長い直鎖のエステル1つで、`--orca-conf 3`とxtbの配座を30個にする試験をしたが、どちらも改善しなかった(最安定の配座が同じ。1化合物だけの確認)。
- **長い直鎖アルキルの13Cは、鎖の炭素が4〜6 ppm高く出た**。xtbの最安定配座(折れ曲がり)と、全antiの伸びた配座(xtbで+0.2 kcal/mol)のどちらでも高く出て、伸ばすと悪化した(MAE 2.68 → 4.92 ppm)。実測は、ねじれた配座を含む平均なので、1配座の計算では再現できないとみられる(配座の分布を取るMDなどは未検証)。
- 結合したHが12個を超える系は、小さなJを無視して分割する(近似)。
- CH2の2つのHは、構造が同じなら区別せず平均する(ジアステレオトピックなHは区別しない)。
- 溶媒は連続誘電体モデルのみ。水素結合など特異的な効果は入らない。
- ラジカルや金属錯体には未対応。
